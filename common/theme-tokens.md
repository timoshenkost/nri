# Токены темы

`common/common.css` не содержит ни одного конкретного цвета — он полностью
построен на переменных, которые задаёт `theme.css` в папке персонажа. Чтобы
сделать новую тему, скопируйте любой существующий `theme.css` и поменяйте
значения; трогать общие файлы не нужно.

## Обязательные токены

| Токен | Что задаёт |
|---|---|
| `--page-bg` | фон страницы целиком (можно градиент или узор) |
| `--surface` | подложка шапки и навигации |
| `--card` | фон закрытой карточки |
| `--card-open` | фон раскрытой карточки |
| `--inset` | полупрозрачная вложенная подложка (тело карточки, таблицы) |
| `--inset-solid` | непрозрачная подложка для полей ввода |
| `--accent` | основной цвет темы |
| `--accent-light` | светлый оттенок для заголовков и подписей |
| `--accent-soft` | едва заметная заливка акцентом для кнопок |
| `--text` | основной текст |
| `--muted` | второстепенный текст, неактивные элементы |
| `--gold` | числа и счётчики |
| `--danger` / `--danger-light` | опасные действия |
| `--hp-red` / `--hp-green` | шкала хитов |
| `--border` | обычные разделители |
| `--border-strong` | заметные рамки: кнопки, поля |
| `--btn-bg` | фон нейтральной кнопки |
| `--radius` | базовое скругление |
| `--font-body` / `--font-mono` | шрифты |
| `--glow` | тень под шапкой |
| `--card-open-glow` | тень раскрытой карточки (можно `none`) |
| `--header-border` | нижняя граница шапки целиком, например `3px solid var(--accent)` |
| `--title-shadow` | свечение заголовка (можно `none`) |
| `--title-spacing` | межбуквенный интервал заголовка |
| `--badge-conc-fg` | метка концентрации «К» — буква и обводка |
| `--badge-ritual-fg` | метка ритуала «Р» — буква и обводка |
| `--coin-pp` / `--coin-gp` / `--coin-sp` / `--coin-cp` | монеты кошелька: платина, золото, серебро, медь |

Звезда бесплатного каста рисуется цветом `--gold`, поэтому метки лучше
задавать другими цветами, иначе они сливаются.
